# Nom de l'aplicació

Biblioteca de videojocs

## Autor/a

Nil Garcia Cuatrecasas

## Descripció

Aplicació Angular desenvolupada per a l'EAC1 de l'assignatura OA01 Programació Avançada de l'Institut Obert de Catalunya (IOC).

## Versions utilitzades

Node.js 24.21.0
Angular CLI 22.2.2
Angular 22.2.2
npm 11.19.0
Git 2.54.0.windows.1

## Com crear i executar el projecte

ng new ioc-angular-biblioteca-videojocs-nil-garcia --routing --style=scss --ssr=false --standalone=true --file-name-style-guide=2016 --skip-git=true --package-manager=npm
npm install
ng serve

## Estat de l'EAC1

Projecte base funcional amb la pàgina principal personalitzada i el hot reload comprovat.
